# Credits

Below is a list of anyone whose work has assisted in the creation of this project. I try to be very cautious about using things others have made appropriately, which extends to crediting. Please feel free to contact me here, on Discord (mr_sharpie93) or BlueSky (@sharpie93.bsky.social) to offer corrections, or request credit or removal.
